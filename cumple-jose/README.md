# Feliz cumpleaños, José

Carta HTML para el padrino. El tono es formal y familiar: sobre de lacre, papel crema y un retrato en su proporción real.

La foto mide **1078×1440** y se ve completa, sin recorte. El retrato queda a la izquierda y el mensaje a la derecha.

## Flujo WhatsApp

1. La foto ya está en:

```text
cumple-jose/assets/jose.jpg
```

2. Genera el HTML autocontenido:

```bash
cd cumple-jose
python3 build-whatsapp.py
```

3. Envía `feliz-cumple-jose.html` por WhatsApp.

## Experiencia

1. Sobre verde salvia con lacre **J**
2. Al tocarlo: el sello cede y aparece la dedicatoria
3. Carta con el retrato completo, el mensaje y la firma `atte Ubani`

## Nota

Pensada para teléfono y para los WebViews de WhatsApp.
