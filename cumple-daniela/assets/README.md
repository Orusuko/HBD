# Foto de Daniela

Coloca aquí la imagen con uno de estos nombres:

- `daniela.jpg` (recomendado)
- `daniela.jpeg`
- `daniela.png`
- `daniela.webp`

Luego, desde la carpeta `cumple-daniela/`, genera el HTML para WhatsApp:

```bash
python3 build-whatsapp.py
```

Eso crea `feliz-cumple-daniela.html` con la foto ya dentro del archivo.
