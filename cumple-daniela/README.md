# Feliz cumpleaños, Daniela

Tarjeta HTML interactiva estilo sobre VIP de cine.

## Cómo usarla

1. Guarda la foto de Daniela como:

```text
cumple-daniela/assets/daniela.jpg
```

2. Abre `index.html` en el navegador (Chrome, Safari o Firefox).
3. Toca el sobre para abrir la carta.

### Alternativa rápida

Si aún no está el archivo en `assets/`, abre la carta y **arrastra la foto al polaroid** (o tócalo cuando diga que falta la imagen). Queda guardada en ese navegador.

## Compartir

Envía la carpeta completa `cumple-daniela/` (HTML + `assets/daniela.jpg`), o súbela a cualquier hosting estático y comparte el enlace.
